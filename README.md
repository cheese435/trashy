# trashy - WIP!
A relaxing game about sweeping away trash and collecting knick knacks!

Some assets are *not mine* and belong to their respective owners!
ui 100% not "borrowed" from terra ;)

Made for [Terra](terra.hackclub.com)

Click the trash to move it *away* from where your cursor is, and guide it towards the bin!

You can view the live demo [here](https://cheese435.github.io/trashy/trashy.html).
